- jsx
    -syntax extension for JavaScript 
    - lets you write HTML-like markup directly inside your JavaScript or TypeScript code.
    - Charecteristics:
        - UI Description:
            describes what the user interface should look like by producing React Elements or virtual DOM nodes.

        - Not Direct Browser Code:
            - Browsers cannot run JSX natively. 
            - Build Tools and compilers like Babel, SWC, or esbuild transform JSX into standard React.CreateElement() JavaScript calls before execution

        - Embeded Expressions:
            - can embed any valid JavaScript expression inside JSX by wrapping it in curly braces {}

    - Syntax Rules:
        - Single Root Elements:
            - A JSX expression must return a single top-level element or a React Fragment(<>...</>).
        - CamelCase Attributes:
            - HTML attributes use camelCase in JSX instea of lowercase (for example, "className" instead of "class", and "htmlFor" instead  of "for" ).
    - js engine understand ECMAScript . Browser won't understand jsx
    - bable in parcel transpiles jsx into javascript(ECMAScript)

-Config Driven UI
    - a.k.a - Server Driven UI or Dynamic UI
    - Design pattern
    - structure of layout , behavior, of a user interface are defined using external configuration data. (JSON or JavaScript Objects)

    - How It Works

    - 1. The Config (Data): A backend server, CMS, or local file sends a structured data object describing what should appear on the screen.
        • Example: { type: "carousel", data: { title: "Deals", items: [...] } }
    - 2. The Renderer (Code): The frontend application receives the config and maps each type key to a pre-built UI component.
    - 3. The Display: The app dynamically mounts and renders the elements on the fly.


    - Common Use Cases

    -  Dynamic Dashboards: Reordering or resizing widgets per user role.
    -  Forms: Rendering login, checkout, or survey fields with custom validation rules dynamically.
    -  E-Commerce & Media Apps: Swapping out home page carousels, banner ads, and product grids (used widely by platforms like Airbnb, Spotify, and Uber).
